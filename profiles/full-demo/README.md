# Full demonstration profile

The integration profile used to demonstrate modularity, not the recommended
starting point for every user.

Target sequence:

1. Remote/native MXL sources enter Core.
2. Operator cuts direct shots and 2-up through 8-up layouts.
3. EIC health and NMOS state remain visible.
4. Program records into a time-addressable archive.
5. The operator grabs the last ten seconds, loads replay into Preview, and cuts
   it to Program while recording continues.
6. One external output is restarted without disturbing Core, recording, or the
   other destination.

**Status:** profile definition. It must pin only candidate or accepted packages
before being advertised as reproducible.
