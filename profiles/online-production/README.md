# Online-production profile

For webinars, remote meetings, virtual events, and cloud production.

## Default selection

- Core and browser Skin
- EIC health and remote Companion control
- ZoomISO/native MXL or SRT contribution
- SuperSource compositor and confidence multiview
- meeting-return output
- WebRTC confidence output
- SRT and RTMPS distribution

SDI hardware and TAMS are not selected by default.

**Status:** profile definition; package versions will be pinned as adapters
reach candidate status.
