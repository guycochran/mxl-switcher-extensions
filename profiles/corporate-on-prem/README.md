# Corporate/on-prem profile

For ballrooms, studios, campuses, and production trucks.

## Default selection

- Core and reference Skin
- Companion/Stream Deck control
- EIC health
- SRT and RTSP contribution
- NDI I/O where licensed and installed
- optional DeckLink scheduled SDI/HDMI output
- presentation and file-playback sources
- conventional file recorder

TAMS, ZoomISO, public cloud, and RTMPS are not selected by default.

**Status:** profile definition; package versions will be pinned as adapters
reach candidate status.
